# Little Lemon Booking App

This is a React-based web application for the Little Lemon restaurant to handle table bookings.

## Features
- User-friendly booking form (Name, Email, Date, Time, Guests).
- Form validation with meaningful error messages.
- Edge case handling (e.g., guests between 1-10).
- Responsive design for mobile and desktop.
- Accessible form fields using aria-labels.

## How to Run
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the development server.
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Testing
Run `npm test` to execute the unit tests.
